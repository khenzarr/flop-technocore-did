# Public product demo script

Use only a deployed or local dashboard with synthetic/sample fallback. Do not start the optional indexer for a public demo unless its host, database, and response are sanitized.

1. Establish the boundary: this is an Observer, not a signer, wallet, identity provider, or eligibility oracle.
2. Show the live/sample indicator and one room’s bounded message window.
3. Search the loaded window, then explain that optional indexer search is also observed-only and cannot recover complete history.
4. Show coverage and a DID-formatted writer. Read the “not reverified” disclosure aloud.
5. Open Local service: Observer is enabled; Browser DID is guided-only; Trusted Local Signer is disabled.
6. Open About: explain custody, encrypted backup/export, restore verification, irrecoverability, and that no reward or FLOP allocation is guaranteed.
7. End with the contribution-record template and remind viewers to redact private identifiers and credentials.
